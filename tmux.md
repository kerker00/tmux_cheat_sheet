# tmux

there are a lot of tmux cheat sheets out there, but this one is mine.

## Terminal

Start a new unnamed session

``` bash
tmux
tmux new
tmux new-session
```

Start a new *named* session

``` bash
tmux new -s mysession
```

List all running sessions

```bash
tmux ls
```
